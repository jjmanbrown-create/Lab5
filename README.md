# Lab 5 – Java Programming Projects

This repository contains four Java programming projects completed as part of CISC 230 (Object-Oriented Design and Programming) at the University of St. Thomas. Each task focuses on applying Java programming concepts through interactive applications and problem-solving exercises.

## Task 1: Interactive Campus Explorer
Developed an interactive campus explorer that displays different landmark locations throughout the University of St. Thomas.

**Features:**
- Display multiple campus landmarks and locations.
- Use JavaFX FlowPane and BorderPane layouts to organize interface components.
- Incorporate buttons to navigate between different locations.
- Display different images based on user button selections.

## Task 2: Campus Applicant Eligibility System
Created a program that evaluates and compares campus applicants based on their academic performance, completed credits, campus activities, and good standing.

**Features:**
- Store and display individual applicant information.
- Evaluate applicants based on eligibility requirements.
- Compare applicants using GPA, activities, and other ranking criteria.
- Select the best eligible applicant.
- Include multiple test cases to verify eligibility and applicant comparisons.

## Task 3: Number Guessing Game
Developed an interactive number guessing game where users select a difficulty level and attempt to guess a randomly generated number.

**Features:**
- Multiple difficulty levels with different number ranges and attempt limits.
- Provide feedback when guesses are too high or too low.
- Award points based on the number of attempts used.
- Track games played, won, and lost, along with total points.
- Support multiple rounds and generate a final game report.

## Task 4: Interactive Vending Machine
Created an interactive vending machine program that allows users to purchase products, check inventory, and restock available items.

**Features:**
- Display available products and their information.
- Purchase products using product codes.
- Manage inventory by reducing quantities after purchases.
- Restock products when inventory is low.
- Track successful purchases and total revenue.
- Generate inventory reports and a final purchase summary.
